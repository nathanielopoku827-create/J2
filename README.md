# ARMED FORCES RECRUITMENT PORTAL

A simple recruitment application form for Armed Forces enlistment.

This is a frontend-only project built with HTML and CSS

![Form Screenshot](screenshot.png)

## 🚀 Live Demo
https://nathanielopoku827-create · he/him.github.io/armed-forces-recruitment/

## ✨ Features

- Full Name input field
- Date of Birth picker (dd/mm/yyyy)
- Gender selection (Male / Female)
- Preferred Branch dropdown
- Resume / CV file upload
- Submit Application button
- Clean and responsive design

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling
